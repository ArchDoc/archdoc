The explorer's map is easier to read. Boxes are colored by what they are (people and teams, agents, systems, containers, components, datastores, queues, externals), with the kind named on each box and a key on the map; the journey lanes and the minimap use the same colors. Every use says what it's for beside its line, without hovering: the layout keeps room for each description, so lines no longer run under them, and rows of boxes sit far enough apart to see which way each arrow points. Turn descriptions off from the key for a tighter map. Journeys open on the map, each line labeled with what its steps do there; switch to Sequence for the lanes, and the explorer remembers which you picked.
