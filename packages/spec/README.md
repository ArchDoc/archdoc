# @archdoc/spec

The ArchDoc model format: its schema (Zod), TypeScript types, JSON Schema for editors, and migration from v1 models.

This package is part of [ArchDoc](https://archdoc.github.io), and is published for the `archdoc` command and its MCP server to use. **You probably want [`@archdoc/cli`](https://www.npmjs.com/package/@archdoc/cli).** `archdoc schema` prints the JSON Schema; this package also serves it at `@archdoc/spec/schema.json`.

Its JavaScript API isn't covered by ArchDoc's [compatibility promise](https://github.com/ArchDoc/archdoc/blob/main/COMPATIBILITY.md) and may change in any release. Install the same version of every `@archdoc/*` package.
