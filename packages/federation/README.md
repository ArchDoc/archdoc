# @archdoc/federation

Sharing ArchDoc models across repositories: `archdoc sync` and `archdoc publish`. Experimental: see [docs/experimental.md](https://github.com/ArchDoc/archdoc/blob/main/docs/experimental.md).

This package is part of [ArchDoc](https://archdoc.github.io), and is published for the `archdoc` command and its MCP server to use. **You probably want [`@archdoc/cli`](https://www.npmjs.com/package/@archdoc/cli).**

Its JavaScript API isn't covered by ArchDoc's [compatibility promise](https://github.com/ArchDoc/archdoc/blob/main/COMPATIBILITY.md) and may change in any release. Install the same version of every `@archdoc/*` package.
